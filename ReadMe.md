# Mein erstes Tetris-Projekt 🕹️

Ein klassisches Tetris-Spiel, entwickelt in Python mit der Bibliothek **Pygame** und tatkräftiger Unterstützung von KI. Entstanden als Lernprojekt für die Programmierung und die Git-Versionierung.

## Voraussetzungen
* Python 3.12+
* Pygame (`pip install pygame`)

## Spiel starten
1. Virtuelle Umgebung aktivieren:

bash
source .venv/bin/activate


2. Spiel ausführen:

bash
python tetris.py

## Steuerung
* **Pfeiltaste Links / Rechts:** Bewegen
* **Pfeiltaste Oben:** Drehen
* **Pfeiltaste Unten:** Schneller fallen lassen
